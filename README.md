# Clothing Classification - Kelompok 22

Paket inferensi Streamlit (CPU). Bobot model dan hasil evaluasi asli, tanpa training ulang.

## Deployment
Upload isi folder ini ke repository GitHub, pilih app.py sebagai entry point di Streamlit Community Cloud, dan gunakan Python 3.12.

## Lokal
`python -m pip install -r requirements.txt`

`python -m streamlit run app.py`

Dataset: https://www.kaggle.com/datasets/agrigorev/clothing-dataset-full

Paket ini untuk inferensi, bukan arsip training lengkap.
